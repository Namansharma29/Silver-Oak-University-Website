# Silver Oak University Website

## About the Project
This is my first HTML practical project created as part of my Web Designing learning at Silver Oak University.

## Features
- University introduction
- Welcome heading
- University banner image
- Courses offered list
- My course section
- Link to the official university website

## Technologies Used
- HTML5
- Inline CSS

## Learning Outcomes
Through this project, I practised HTML headings, paragraphs, images, lists, hyperlinks, and basic text alignment.
